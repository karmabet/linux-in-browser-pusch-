Guest OS: Tiny Core Linux 17.0

The bundled guest is a 32-bit x86 Tiny Core Linux 17.0 desktop. Its ISO identifies Linux kernel 6.18.2-tinycore and BusyBox 1.36.1. The boot extension list includes FLTK, FLWM, Xvesa, Xprogs, wbar, and supporting libraries. Guest components retain their own copyrights and licenses; the GPL license texts are provided here as notices, not as a replacement for component-specific terms.

  • Tiny Core 17.x x86 release source directory
  • Tiny Core 17.x x86 extension source directory
  • Included license texts: GPL-2.0, GPL-3.0.

Emulator: v86 0.5.471+g94faf3d

v86 is the x86 emulator and WebAssembly runtime. The version is pinned in the project dependencies; source reference: v86 source at 94faf3d. License: BSD 2-Clause.

Firmware: SeaBIOS rel-1.16.2

The bundled system BIOS corresponds to SeaBIOS rel-1.16.2. The VGA BIOS is also from the SeaBIOS project. Source reference: SeaBIOS source at rel-1.16.2. The applicable license texts included here are LGPL-3.0 for SeaBIOS and GPL-3.0 for the VGA BIOS.
